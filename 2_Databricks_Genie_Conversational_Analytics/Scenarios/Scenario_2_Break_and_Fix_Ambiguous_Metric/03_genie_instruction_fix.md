# Instruction added to the Genie space (Configure > Instructions)

```text
Fizzco defines "net sales" as the value invoiced to retailers after discounts. It is the column invoiced_amount.
The column net_sales is a legacy name for shopper sales at shelf price. Do not use it for net sales.
When a question says "sales" without a qualifier, use invoiced_amount.
Use net_sales only when the question says "shopper sales" or "retail sales".
```
